## Template

Copie `template.md` para criar um novo PRD.  
Nomenclatura: `PRD-{NNN}-{titulo-kebab-case}.md`

## Status possíveis

- **Draft** — em elaboração
- **In Review** — aguardando revisão do time
- **Approved** — aprovado, pode virar RFC/implementação
- **Rejected** — rejeitado com justificativa
- **Superseded** — substituído por outro PRD
